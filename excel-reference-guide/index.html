🔒 单元格引用锁定

$符号锁定：

  • 绝对引用：$A$1 - 行列都不变
  • 列绝对行相对：$A1 - 列不变，行变化
  • 行绝对列相对：A$1 - 行不变，列变化
⌨️ 常用特殊符号输入（Alt + 数字编码）

在支持数字小键盘输入的环境中，可通过按住 Alt 键并在数字小键盘输入相应编码的方式插入常用符号；松开 Alt 键后符号即会出现。请确保 Num Lock 已开启，且注意不同软件或系统对编码的支持可能存在差异。

  • 勾号（确认/已完成）：Alt + 41420 → √
  • 叉号（否定/未通过）：Alt + 41409 → ×
  • 正负号：Alt + 0177 → ±
  • 度数符号：Alt + 0176 → °
  • 版权符号：Alt + 0169 → ©
  • 注册商标：Alt + 0174 → ®
  • 商标符号：Alt + 0153 → ™
  • 项目符号：Alt + 0149 → •
  • 省略号：Alt + 0133 → …
  • 乘号（数学）：Alt + 0215 → ×（备用编码）

提示：若上述编码在目标应用中无效，可尝试使用其内置的“插入符号”功能或采用复制粘贴方式。

🔢 常用函数

SUMIF - 单条件求和
=SUMIF(range, criteria, sum_range)

参数说明：

  • range：条件区域
  • criteria：求和条件
  • sum_range：实际求和区域
实例：
=SUMIF(A:A,"苹果",B:B)
统计A列中所有"苹果"对应B列的数值总和
SUMIFS - 多条件求和
=SUMIFS(sum_range, criteria_range1, criteria1, criteria_range2, criteria2, ...)
实例：
=SUMIFS(C:C, A:A, "苹果", B:B, ">10")
统计A列为"苹果"且B列大于10的C列数值总和
AVERAGE - 求平均值
=AVERAGE(number1, number2, ...)
实例：
=AVERAGE(A1:A10)
计算A1到A10单元格的平均值
AVERAGEIF - 单条件求平均
=AVERAGEIF(range, criteria, [average_range])
实例：
=AVERAGEIF(A:A, ">=60", B:B)
计算A列中大于等于60的对应B列数值的平均值
MAX/MIN - 最大值/最小值
=MAX(number1, number2, ...)
=MIN(number1, number2, ...)
实例：
=MAX(A1:A10) 返回最大值
=MIN(A1:A10) 返回最小值
ROUND - 四舍五入
=ROUND(number, num_digits)
实例：
=ROUND(3.14159, 2) 返回 3.14
=ROUND(1234.5, -2) 返回 1200
TRUNC - 截取整数
=TRUNC(number, [num_digits])
实例：
=TRUNC(3.99) 返回 3
=TRUNC(123.456, 1) 返回 123.4
IF - 条件判断
=IF(logical_test, value_if_true, value_if_false)
实例：
=IF(A1>=60, "及格", "不及格")
如果A1大于等于60显示"及格"，否则显示"不及格"
IFS - 多条件判断
=IFS(条件1, 值1, 条件2, 值2, ...)
实例：
=IFS(A1>=90,"优秀", A1>=80,"良好", A1>=60,"及格", TRUE,"不及格")
TODAY/NOW - 当前日期时间
=TODAY()
=NOW()
实例：
=TODAY() 返回当前日期
=NOW() 返回当前日期和时间
DATEDIF - 计算日期差
=DATEDIF(start_date, end_date, unit)

Unit参数："Y"年、"M"月、"D"天、"MD"同月天数差、"YD"同年天数差、"YM"同年月数差

实例：
=DATEDIF("2020/1/1", "2023/1/1", "Y") 返回 3（年）
=DATEDIF("2023/1/1", "2023/3/15", "D") 返回天数差
LEFT/RIGHT/MID - 文本提取
=LEFT(text, [num_chars])
=RIGHT(text, [num_chars])
=MID(text, start_num, num_chars)
实例：
=LEFT("Hello World", 5) 返回 "Hello"
=RIGHT("Hello World", 5) 返回 "World"
=MID("Hello World", 7, 5) 返回 "World"
VLOOKUP - 纵向查找
=VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup])
实例：
=VLOOKUP("张三", A:D, 3, FALSE)
在A到D列中查找"张三"，返回第3列的值（精确匹配）
COUNT/COUNTA/COUNTBLANK - 计数函数
=COUNT(value1, value2, ...)
=COUNTA(value1, value2, ...)
=COUNTBLANK(range)
实例：
=COUNT(A1:A10) 统计数字个数
=COUNTA(A1:A10) 统计非空单元格个数
=COUNTBLANK(A1:A10) 统计空白单元格个数
SUBTOTAL - 万能统计函数
=SUBTOTAL(function_num, ref1, [ref2], ...)

Function_num：1-11（包含隐藏值），101-111（不包含隐藏值）

实例：
=SUBTOTAL(9, A1:A10) 对A1:A10求和（包含隐藏行）
=SUBTOTAL(109, A1:A10) 对A1:A10求和（不包含隐藏行）
INDIRECT - 文本转引用（间接引用）
=INDIRECT(ref_text, [a1])

参数说明：

  • ref_text：文本形式的单元格/区域/表名，如 "A1"、"Sheet2!B3"、"B"&E1
  • a1：[可选] 引用样式，省略或TRUE为A1样式；FALSE为R1C1样式
实例：
1) 动态行引用：=INDIRECT("A"&ROW()) 引用当前行的A列
2) 动态工作表引用：=INDIRECT($B$1&"!A1")，当B1=Sheet2 时，等同于 =Sheet2!A1
3) 动态区域求和：=SUM(INDIRECT("B"&E1&":B"&E2))，当E1=2,E2=10 时等同于 =SUM(B2:B10)
提示：
INDIRECT 为易变函数（每次重算都会计算），大量使用会影响性能；与合并单元格、关闭的外部工作簿配合时要注意引用是否有效。
